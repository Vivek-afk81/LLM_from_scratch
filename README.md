# LLM from Scratch

This repository is a personal learning project where I explore the fundamentals of building a **Large Language Model (LLM)** from the ground up.  
It is currently a **work in progress** and only covers the basics so far.

---

## 🚀 Goals
- Understand the core building blocks of LLMs
- Implement simple components step by step
- Document the learning process for future reference

---

## 📚 Current Progress
At this stage, the repo includes:
- Basic tokenization
- Simple embeddings
- Notes and experiments on attention mechanisms (early stage)

---

## 🛠️ Planned Next Steps
- Implement full attention mechanism
- Add training loop with sample dataset
- Explore scaling techniques
- Document experiments and results

---

## ⚠️ Disclaimer
This project is **not a production-ready LLM**.  
It is purely educational and meant to help me (and others) understand the inner workings of modern language models.
